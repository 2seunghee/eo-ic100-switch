# eofm-ovl — EO-IC100 FM 라디오 오버레이 (Ultrahand / Tesla)

게임 중에 오버레이를 열어 이어폰 FM 라디오를 조절합니다. 라디오 앱(eofm)을 `+`로 나가면 라디오가 이어폰에서 계속 나오지만, 앱 밖에서는 볼륨을 바꿀 수 없었습니다. 이 오버레이가 그 일을 합니다.

- 버전: 0.1.1 (2026-10-23). 0.1.0은 열자마자 2168-0002로 중단됐다(sdmc: 미마운트 상태에서 mkdir). 실기기에서 동작 확인(켜기, 볼륨, 숨기면 IF0 반납, 재연결).
- 필요: Ultrahand Overlay(또는 Tesla Menu)와 nx-ovlloader. 오버레이는 L + ↓ + R3(기본)으로 엽니다.
- 라디오 앱과 같은 설정 파일(`/switch/eofm/settings.ini`)의 지역, 찾은 채널, 즐겨찾기를 씁니다.

## 설치

`eofm-ovl.ovl`을 SD의 `/switch/.overlays/`에 복사합니다. Ultrahand 목록에 "EO Radio"로 나옵니다.

## 화면과 조작

| 항목 | 조작 | 동작 |
|---|---|---|
| 상태 | | 켜짐 / 꺼짐 / 이어폰 없음 / 준비 중 / 라디오 앱이 사용 중 |
| 라디오 | A | 켜기 / 끄기(켤 때는 마지막 주파수와 볼륨으로) |
| 볼륨 | ← → (A = +1) | 0~15 |
| 주파수 | ← → / L R | 0.1 MHz / 1 MHz씩 |
| 방송 이동 | ← → (A = 다음) | 찾은 채널(없으면 즐겨찾기)의 이전 / 다음 방송 |
| 어디서나 | ZL / ZR | 이전 / 다음 방송 |
| 찾은 채널 / 즐겨찾기 목록 | A 또는 터치 | 그 주파수로 |

채널 찾기와 즐겨찾기 편집은 라디오 앱에서 합니다. 오버레이는 바꾼 주파수와 볼륨을 닫을 때 settings.ini에 적습니다(다른 줄은 그대로 둡니다).

## 동작 방식

- 라디오 앱과 같은 방법(`fm.c`, IF0 벤더 요청)으로 이어폰의 FM 칩을 조작합니다. 코드는 eofm의 것을 그대로 빌드합니다.
- **IF0은 오버레이가 보이는 동안만 쥡니다.** 닫으면 돌려주므로 라디오 앱을 바로 열 수 있습니다. 라디오 앱이 실행 중이면 오버레이는 "라디오 앱이 사용 중"으로 표시하고 아무것도 보내지 않습니다.
- 꽂은 직후에는 스위치 오디오 모듈이 이어폰을 읽는 중이라 IF0을 건드리지 않습니다. 오디오 모듈이 재생 인터페이스(IF2)를 잡았으면 다 읽은 것으로 보고 바로 씁니다. 그 전에는 꽂은 뒤 6초를 기다립니다.
- 숨겨져 있는 동안에도 스레드가 1초마다 이어폰이 꽂혀 있는지만 확인합니다(USB 요청 없음).
- 한글 표시: libtesla는 시스템 언어가 한국어일 때만 한국어 폰트를 읽습니다. 여기 들어 있는 사본은 언어와 관계없이 읽도록 한 줄 고쳤습니다(`lib/libtesla/include/tesla.hpp`).
- 로그: `/switch/eofm/logs/eofm-ovl.txt` (64 KiB가 넘으면 새로 시작)

## 빌드

```bash
make -C switch/eofm-ovl     # eofm-ovl.ovl (devkitPro libnx). libtesla는 lib/에 들어 있음 (GPL-2.0, WerWolv/libtesla f766e9b)
```
