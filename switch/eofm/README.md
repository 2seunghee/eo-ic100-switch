# eofm — EO-IC100 내장 FM 라디오 (홈브루 NRO)

삼성 EO-IC100 USB-C 이어폰에 들어 있는 FM 라디오를 스위치에서 켜고 조작하는 앱입니다. 화면은 삼성 라디오 앱을 본떠 한글로 만들었습니다. 터치와 버튼을 모두 쓸 수 있습니다.

- 버전: 0.1.0 (2026-10-22). **실기기 미검증.** 빌드는 경고 0이고, RDS 해석 호스트 테스트 10개가 통과했습니다. 화면은 PC 미리보기(`tests/preview_*.png`)로만 확인했습니다.
- 프로토콜 출처: [kjy00302/eo-ic100_radio](https://github.com/kjy00302/eo-ic100_radio) (삼성 프레임워크를 디컴파일해 얻은 벤더 요청)

## 듣는 방법 두 가지

| 출력 | 동작 | 상태 |
|---|---|---|
| **이어폰** (기본) | 이어폰 안의 FM 칩이 라디오를 직접 재생합니다. 스위치 소리와는 상관없습니다. | 가장 단순한 경로 |
| **스피커** | 이어폰은 주파수만 잡습니다. 라디오 소리는 이어폰의 녹음 모드로 USB 마이크를 통해 스위치에 들어오고, 앱이 그것을 본체 스피커로 재생합니다. | 실험적. 시스템 오디오 입력(audin)이 이어폰 마이크를 내주는지, 스위치가 USB 장치가 꽂힌 상태에서 출력을 스피커로 옮겨 주는지(audctl)를 앱이 시험하고 화면과 로그에 결과를 남깁니다 |

출력은 카드 왼쪽 위의 `이어폰`/`스피커` 버튼(터치)이나 오른쪽 스틱 누르기로 바꿉니다. 라디오가 켜진 상태에서 바꾸면 바로 전환됩니다.

## 설치와 실행

1. `eofm-v0.1.0.zip`의 `switch/eofm/eofm.nro`를 SD의 `/switch/eofm/`에 복사합니다.
2. **이어폰을 먼저 꽂고** 몇 초 기다린 뒤 hbmenu에서 실행합니다. 앱은 꽂은 지 6초가 지나야 이어폰을 씁니다(스위치 오디오 드라이버가 꽂을 때 쓰는 통로와 겹치지 않게 하려고).
   - 스피커 출력을 쓰려면 앨범이 아니라 **게임을 R 버튼을 누른 채 실행(타이틀 가로채기)** 하는 것이 좋습니다. 앨범(애플릿) 모드에서는 오디오 입력이 막힐 수 있습니다.
3. 이어폰 줄이 안테나입니다. 줄을 펴면 수신이 좋아집니다.
4. 처음 켤 때 "딱" 소리가 날 수 있습니다(원 프로젝트도 경고함). 처음엔 귀에서 조금 떼고 켜세요.

이어폰 출력으로 들으면서 `+`로 나가면 **라디오는 이어폰에서 계속 나옵니다**(게임하면서 듣기). 끄려면 앱을 다시 열어 전원을 끄거나, `B`(끄고 나가기)를 누르거나, 이어폰을 뽑습니다. 스피커 출력은 앱이 재생하는 것이라 나가면 꺼집니다.

## 조작

| 버튼 | 터치 | 동작 |
|---|---|---|
| A | 전원 버튼 | 라디오 켜기/끄기 |
| X | 채널 찾기 | 전 대역을 훑어 방송을 찾아 "채널" 목록에 넣음(다시 누르면 중지) |
| Y | 주파수 옆 별 | 즐겨찾기 추가/삭제 |
| ← → (길게 누르면 반복) | 양옆 화살표 | 0.1 MHz씩 이동 |
| L / R | | 이전/다음 방송 자동 탐색 |
| ↑ ↓ | | 볼륨(0~15). 스피커 출력에서는 녹음 레벨이고 소리 크기는 본체 볼륨으로 조절 |
| ZL / ZR | 목록의 주파수 | 목록(즐겨찾기 또는 채널)의 이전/다음 주파수로 |
| − | 아래 탭 | 즐겨찾기 / 채널 탭 전환 |
| 오른쪽 스틱 누르기 | `이어폰`/`스피커` 버튼 | 출력 전환 |
| 왼쪽 스틱 누르기 | | 모노/스테레오 |
| + | | 나가기(이어폰 출력이면 라디오는 계속 켜짐) |
| B | | 라디오 끄고 나가기 |

화면 맨 위에는 방송국 이름(RDS PS)이 나옵니다. 받지 못하면 주파수가 나옵니다. 그 아래에는 RDS 문자(라디오텍스트)나 상태가 나옵니다. 한국 방송은 RDS를 보내지 않는 곳이 많습니다.

## 설정과 로그

- `/switch/eofm/settings.ini`: 지역(`region=kr|eu|us|jp`), 마지막 주파수·볼륨·출력, 즐겨찾기(`favorites=`), 찾은 채널(`channels=`). 주파수는 10 kHz 단위입니다(8910 = 89.1 MHz). 지역별 대역·간격: kr/eu 87.5~108 MHz 0.1 MHz, us 87.9~107.9 MHz 0.2 MHz, jp 76~95 MHz 0.1 MHz.
- `/switch/eofm/logs/eofm_<날짜_시각>.txt`: 보낸 명령과 결과, 스피커 출력 시험 결과(오디오 입력 목록, 출력 대상 전환 결과)를 남깁니다. 문제가 있으면 이 파일을 보내 주세요.

## 다른 프로그램과 함께 쓰기

- **usbhs-logmitm(스위치 USB 오디오)** 과 함께 씁니다. 스위치 소리는 이어폰으로, 라디오는 이 앱으로 듣습니다. 이어폰 출력에서 라디오와 스위치 소리가 섞여 나오는지는 실기기에서 확인해야 합니다.
- **eoaudio**처럼 이어폰 인터페이스를 모두 잡는 프로그램이 있으면 "다른 프로그램이 이어폰을 쓰고 있습니다"가 뜹니다.

## 빌드

```bash
make -C switch/eofm                 # eofm.nro (devkitPro: libnx + portlibs freetype)
make -C switch/eofm/tests check     # RDS 해석 테스트
make -C switch/eofm/tests preview   # PC 화면 미리보기 (호스트 freetype, Windows 맑은 고딕) → python3 tests/ppm2png.py
```

소스: `main.c`(화면·조작·라디오 상태), `fm.c`(이어폰 IF0 확보, 벤더 요청), `rds.c`(RDS 해석), `speaker.c`(오디오 입력 → 본체 스피커), `gfx.c`(프레임버퍼 그리기, 스위치 내장 한국어 폰트).
