# eofm — EO-IC100 내장 FM 라디오 (홈브루 NRO)

삼성 EO-IC100 USB-C 이어폰에 들어 있는 FM 라디오를 스위치에서 켜고 조작하는 앱입니다. 라디오 소리는 **이어폰 안의 FM 칩이 직접 재생**합니다. 화면은 삼성 라디오 앱을 본떠 한글로 만들었고, 터치와 버튼을 모두 쓸 수 있습니다.

- 버전: 0.2.2 (2026-10-22). 이어폰 전용입니다.
- 실기기 확인(HOS 22.1.0, `04e8:a05b`, 제주): 방송 수신(99.1 MHz 등), 채널 찾기(14개), ZL/ZR 이동, 즐겨찾기, 저장 채널 터치 이동.
- 프로토콜 출처: [kjy00302/eo-ic100_radio](https://github.com/kjy00302/eo-ic100_radio) (삼성 프레임워크를 디컴파일해 얻은 벤더 요청)
- 스피커 출력(라디오를 본체 스피커로)은 시도했다가 뺐습니다. 두 방법 모두 스위치 오디오 모듈을 중단시켰습니다. 기록은 [attic/README.md](attic/README.md)에 있습니다.

## 설치와 실행

1. `switch/eofm/eofm.nro`를 SD의 `/switch/eofm/`에 복사합니다.
2. **이어폰을 먼저 꽂고** 몇 초 기다린 뒤 hbmenu에서 실행합니다. 앱은 꽂은 지 6초가 지나야 이어폰을 씁니다(스위치 오디오 드라이버가 꽂을 때 쓰는 통로와 겹치지 않게).
3. 이어폰 줄이 안테나입니다. 줄을 펴면 수신이 좋아집니다.
4. 처음 켤 때 "딱" 소리가 날 수 있습니다. 귀에서 조금 떼고 켜세요.

`+`로 나가면 **라디오는 이어폰에서 계속 나옵니다**(게임하면서 듣기). 끄려면 앱을 다시 열어 전원을 끄거나, `B`(끄고 나가기)를 누르거나, 이어폰을 뽑습니다. 라디오와 스위치 소리는 이어폰에서 함께 나옵니다.

usbhs-logmitm 0.3.1 이상이 있으면 **이어폰 리모컨의 볼륨 버튼**이 라디오가 켜져 있는 동안 라디오 볼륨을 바꿉니다(앱이 꺼져 있어도). 앱 화면의 볼륨 숫자는 앱의 ↑↓로 바꾼 값이라 리모컨으로 바꾼 값과 다를 수 있습니다.

## 조작

| 버튼 | 터치 | 동작 |
|---|---|---|
| A | 전원 버튼 | 라디오 켜기/끄기 |
| X | 채널 찾기 | 87.5→108 MHz를 0.1 MHz씩 훑어(소리 끈 채, 약 20초) 방송을 찾아 "채널" 목록에 넣음. 다시 누르면 중지 |
| Y | 주파수 옆 별 | 즐겨찾기 추가/삭제 |
| ← → (길게 누르면 반복) | 양옆 화살표 | 0.1 MHz씩 이동 |
| L / R | | 1 MHz씩 이동 |
| ZL / ZR | | 채널 목록의 이전/다음 방송으로(목록이 없으면 칩의 자동 탐색) |
| ↑ ↓ | | 볼륨(0~15) |
| 오른쪽 스틱 ← → | 목록의 주파수 | 보고 있는 목록(즐겨찾기/채널)의 이전/다음 주파수 |
| − | 아래 탭 | 즐겨찾기 / 채널 탭 전환 |
| 왼쪽 스틱 누르기 | | 모노/스테레오 |
| + | | 나가기(라디오는 계속 켜짐) |
| B | | 라디오 끄고 나가기 |

화면 맨 위에는 방송국 이름(RDS)이 나오고, 받지 못하면 주파수가 나옵니다. 한국 방송은 RDS를 보내지 않거나 오류가 많아 거의 나오지 않습니다. 카드 오른쪽 위의 "신호"는 칩이 알려 주는 신호 세기입니다(실측: 잡음 약 15~20, 방송 25~45).

## 설정과 로그

- `/switch/eofm/settings.ini`: 지역(`region=kr|eu|us|jp`), 마지막 주파수·볼륨, 즐겨찾기(`favorites=`), 찾은 채널(`channels=`), 채널 찾기의 잡음 수준(`noise=`)과 방송 판정 여유(`station_margin=`, 기본 6). 주파수는 10 kHz 단위입니다(8910 = 89.1 MHz).
- `/switch/eofm/logs/eofm_<날짜_시각>.txt`: 보낸 명령과 결과, 주파수별 신호 세기, 채널 찾기의 신호 표. 줄마다 파일을 닫으므로 앱이 실행 중이어도 DBI로 복사할 수 있습니다.

## 칩에 대해 알아낸 것 (실기기)

- 켜는 순서는 전원 → 0.2초 → 볼륨 → 주파수여야 합니다. 켜자마자 대역·간격·RDS를 보내면 잡음만 나왔습니다(0.1.0).
- `GET_CURRENT_RSSI`는 항상 0입니다. 신호 세기는 `QUERY` 응답에 들어 있습니다(맞춤 결과 type 1, 탐색 결과 type 0의 5번째 바이트, RDS type 2의 3번째 바이트).
- `QUERY`는 새 일이 생길 때까지 마지막 결과를 계속 되풀이합니다. 그래서 앱은 결과가 "이번 것"인지 주파수로 확인합니다.
- 칩의 자체 탐색은 방송 위에서 시작하면 그 자리에서 멈춥니다. 앱은 한 칸 옆에서 시작합니다.
- 탐색이 끝났다는 알림은 IF4 인터럽트로 오는데, 이 인터페이스는 스위치 hid가 잡고 있어(또는 usbhs-logmitm이 숨겨) 쓰지 않습니다.

## 빌드

```bash
make -C switch/eofm                 # eofm.nro (devkitPro: libnx + portlibs freetype)
make -C switch/eofm/tests check     # RDS 해석 테스트
make -C switch/eofm/tests preview   # PC 화면 미리보기 (호스트 freetype, Windows 맑은 고딕) → python3 tests/ppm2png.py
```

소스: `main.c`(화면·조작·라디오 상태·채널 찾기), `fm.c`(이어폰 IF0 확보, 벤더 요청), `rds.c`(RDS 해석), `gfx.c`(프레임버퍼 그리기, 스위치 내장 한국어 폰트).
